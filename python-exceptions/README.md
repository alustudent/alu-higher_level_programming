# Python - Exceptions

| File | Description |
|------|-------------|
| `0-safe_print_list.py` | Prints up to `x` elements of a list and returns how many were printed |
| `1-safe_print_integer.py` | Prints a value with `{:d}` and returns whether it is an integer |
| `2-safe_print_list_integers.py` | Prints the integers among the first `x` elements of a list |
| `3-safe_print_division.py` | Divides two integers and prints the result in `finally` |
| `4-list_division.py` | Divides two lists element by element, handling errors |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |
