# Python - Network #0

HTTP basics with `curl`: request methods, headers, POST data and following redirects.

| File | Description |
|------|-------------|
| `0-body_size.sh` | Displays the size in bytes of a response body |
| `1-body.sh` | Displays the body of a 200 response, following redirects |
| `2-delete.sh` | Sends a `DELETE` request and displays the body |
| `3-methods.sh` | Displays the HTTP methods a server accepts |
| `4-header.sh` | Sends a `GET` request with a custom header |
| `5-post_params.sh` | Sends a `POST` request with `email` and `subject` |
