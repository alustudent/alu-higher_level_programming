The ``1-my_list`` module
========================

Using ``MyList``
----------------

    >>> MyList = __import__('1-my_list').MyList

MyList is a list:

    >>> issubclass(MyList, list)
    True

An empty list prints an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Elements print sorted, but the list itself is unchanged:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers and duplicates:

    >>> my_list = MyList([3, -1, 3, 0, -7])
    >>> my_list.print_sorted()
    [-7, -1, 0, 3, 3]

An already sorted list:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

print_sorted returns a new list each time:

    >>> my_list = MyList([2, 1])
    >>> my_list.print_sorted()
    [1, 2]
    >>> my_list
    [2, 1]
