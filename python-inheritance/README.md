# Python - Inheritance

Class inheritance, `super()`, `isinstance`/`issubclass`, and overriding built-in methods.

| File | Description |
|------|-------------|
| `0-lookup.py` | Returns the list of attributes and methods of an object |
| `1-my_list.py` | `MyList`, a `list` subclass with `print_sorted()` |
| `2-is_same_class.py` | Checks if an object is exactly an instance of a class |
| `3-is_kind_of_class.py` | Checks if an object is an instance of a class or a subclass |
| `4-inherits_from.py` | Checks if an object's class only inherits from a class |
| `5-base_geometry.py` | Empty `BaseGeometry` class |
| `6-base_geometry.py` | Adds an unimplemented `area()` |
| `7-base_geometry.py` | Adds `integer_validator()` |
| `8-rectangle.py` | `Rectangle` with validated private width and height |
| `9-rectangle.py` | Adds `area()` and `__str__` |
| `10-square.py` | `Square` that inherits `Rectangle` |
| `11-square.py` | `Square` with its own `__str__` |
| `tests/` | Doctests for `1-my_list.py` and `7-base_geometry.py` |
