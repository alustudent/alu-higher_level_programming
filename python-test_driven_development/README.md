# Python - Test-driven development

Writing doctests and unittests before and alongside code, and documenting modules and functions.

| File | Description |
|------|-------------|
| `0-add_integer.py` | Adds two integers or floats, cast to `int` |
| `2-matrix_divided.py` | Divides every matrix element, rounded to 2 decimals |
| `3-say_my_name.py` | Prints `My name is <first> <last>` |
| `4-print_square.py` | Prints a square of `#` |
| `5-text_indentation.py` | Prints text with 2 new lines after `.`, `?` and `:` |
| `6-max_integer.py` | Returns the max integer of a list |
| `tests/*.txt` | Doctests for tasks 0 to 4 |
| `tests/6-max_integer_test.py` | Unittests for `max_integer` |
